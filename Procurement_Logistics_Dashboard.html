Panduan Sekali Setup (oleh admin/IT)

  1. Buka Google Cloud Console → buat project baru → aktifkan Google Sheets API.
  2. Buat OAuth Client ID tipe "Web application". Di "Authorized JavaScript origins", isi alamat tempat file dashboard ini di-hosting (harus https://, bukan file lokal — bisa pakai GitHub Pages, Netlify, atau link publish Claude).
  3. Salin Client ID yang dihasilkan, lalu tempel di kode dashboard pada baris GOOGLE_CLIENT_ID (cari di bagian atas script), lalu simpan ulang filenya.
  4. Untuk fitur kirim email: aktifkan juga Gmail API di project yang sama, dan tambahkan izin gmail.send pada menu Google Auth platform → Data Access.
  5. Pastikan spreadsheet Pakta Integritas dibagikan (Share) dengan akun Google setiap anggota tim sebagai Editor.
  6. Setiap anggota tim membuka dashboard ini dari alamat hosting yang sama, lalu klik "Hubungkan Akun Google" di bawah dan login dengan akun masing-masing.

Catatan: tombol di bawah belum berfungsi sebelum GOOGLE_CLIENT_ID diisi dan file dibuka dari alamat https (bukan dibuka langsung sebagai file di komputer).
